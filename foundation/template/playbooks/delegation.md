# Delegation

The COS communicates and dispatches. Each manager owns an outcome and coordinates its workers; each specialist owns requested deliverables; each worker answers to its parent. Large research or coding work uses a fresh bounded worker session and returns a compact artifact and evidence.

A handoff has: exact goal, scope and off-limits list, source/context packet, deliverable, acceptance criteria, owner, due date, budget, and return destination. Track proposed → accepted → running → submitted → independently verified → closed. A transport receipt is not acceptance; a completion message is not verified execution.

GOALS.md for managers/specialists:

    ## Goal: what done looks like
    - Blocker: none | what (checked timestamp)
    - [ ] next action, owner, due date

OPEN.md for other seats:

    ## Item
    - Owner:
    - Goal:
    - Now:
    - Next:
    - Blocker:

Keep current state concise; archive historical outcomes separately. A specialist sleeps when requests and helpers are finished. Workers have no independent schedule.
