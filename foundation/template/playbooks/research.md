# Research engine contract

COS and configured department strategists submit a single bounded decision with a locked goal card and a frozen current context packet. Modes: answer, compare, plan or watch. The backend checks the existing evidence library first and enforces per-company and per-team budgets, concurrency and review cadence.

1. Judge sizes the job and selects source classes and model routes.
2. Independent researchers return atomic claims supported by exact quotes from saved snapshots.
3. Deterministic checks verify snapshot membership, quoted text, arithmetic, source class and duplicate claims. Judge evaluates the bounded claim.
4. Breaker attacks each supported claim against the full sources; only explicit STANDS promotes it to verified.
5. Director and challenger independently identify gaps and next questions. The backend readiness gate decides READY, never a seat's assertion.
6. Planner cites verified ids only. Code checks goal, constraints, citations and measurement of gaps. Independent verifiers return PASS, FAIL or HUMAN REVIEW.
7. Release challenge and applicable owner approval precede execution.

Keep claims, gaps, snapshots, questions, model routes, costs, verdicts and plan attempts in the run ledger. A missing answer is a valid result. Failed model/judge calls create a systems incident; paused jobs resume only with the same frozen inputs. This playbook defines the existing house process; connect the verified research backend before using it. Roles alone do not perform code or model checks.
